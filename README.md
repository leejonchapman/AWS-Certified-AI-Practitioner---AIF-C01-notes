# About the Exam (AIF-C01)
- **Format**: Multiple Choice, Multiple Response, Ordering, Matching.
- **Questions**: 50 scored, 15 unscored (65 total).
- **Time**: 120 minutes.
- **Passing Score**: Scaled score of 700 (Scale 100 - 1000).
- **Target Candidate**: Up to 6 months of exposure to AI/ML technologies on AWS. Uses but does not necessarily build AI/ML solutions.
